# Реестр: правило промпта → исполнитель ниже модели (§14.2a)

У каждого поведенческого правила из `data/prompts/` либо есть исполнитель ниже
модели, либо стоит пометка **advisory** — тогда правило держит только модель.
Шаблоны `data/prompts/templates/*` произносятся дословно, правил для модели в них
нет. Составлен 2026-10-01 по `data/prompts/*` и `data/contracts/*` на `main`
55625ed; номера строк — по промпту.

Исполнители:

- `backend/app/contracts/enforcer.py` — проверки `RUNTIME_CHECKS` из
  `contracts/spec.py`. Режут фразу **до озвучки**: перегенерация → отбросить хвост
  → запасная реплика `seed`. Проверки из `DECLARATIVE_CHECKS` объявлены в YAML, но
  в рантайме не исполняются — у правил с ними пометка advisory.
- Оркестраторы `backend/app/orchestrator/` — структура хода: вопрос, фаза, счётчики.
- `backend/app/summary/validate.py` — разбор и проверка вывода суммаризации.

## `summary_system.txt` и `minimal_summary_system.txt` — сводка после сессии

| Правило | Исполнитель | Статус |
|---|---|---|
| Только валидный JSON по схеме, поля-списки — списки | S-H1 в `validate.py`; один повтор с ошибкой, затем минимальная сводка | исполняется |
| Ответ не пуст после вырезания размышлений | S-H5 в `validate.py` | исполняется |
| Текстовые поля по-английски | S-H2 в `validate.py:140` | исполняется для кириллицы |
| `translation_ru` — кириллица, без CJK | S-H6: плохой перевод переводится заново на qwen или отбрасывается с записью в лог | исполняется |
| Баллы — целые от 1 до 5 | S-H3 в `validate.py:119` | исполняется |
| Запись словаря полна: `term_en`, `translation_ru`, `example_en` | S-H4 в `validate.py` | исполняется |
| 5–12 терминов, 2–3 слабых ответа, цитаты и номера вопросов, флаг позиционирования | — | advisory |

Каждый `invariants.hard[].id` контракта суммаризации обязан оставить маркер в
коде `backend/app/summary/` — это сторожит `backend/tests/test_contracts.py`.

## Чего реестр не даёт

Он называет исполнителей, но не доказывает, что исполнитель держит правило: это
показала бы порча промпта (§14.5), а её в проекте пока нет. Расхождение «4
предложения в промпте против 5 в контракте» у разбора записано здесь, но не
исправлено.
