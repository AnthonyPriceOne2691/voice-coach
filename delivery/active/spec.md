# Spec: REST-запросы фронта доходят до бэкенда в dev-режиме

## Задача

В `./scripts/dev.sh` вкладки History и Useful Words не работают: Vite не
проксирует `/sessions` и `/vocabulary`, запрос уходит в SPA-fallback и
возвращает HTML с кодом 200. Разбор — `active/diagnosis.md`.

## Инвариант

**Каждый префикс, который зовёт клиент, проксируется dev-сервером** — и это
проверяется машиной, а не вниманием. Забытый префикс обязан ронять тест, а не
вкладку в браузере.

## Что меняется

1. `vite.config.ts` проксирует префиксы, которые реально зовёт `lib/api.ts`.
   Правило `/api`, которого не зовёт никто, убирается: именно оно делало конфиг
   похожим на рабочий.
2. **Тест-сторож**: сверяет префиксы из `lib/api.ts` со списком в
   `vite.config.ts`. Новый эндпоинт без прокси падает в CI, а не в браузере.
3. **Ошибка перестаёт быть немой**: клиент отличает «пришёл не JSON» от
   «бэкенд не отвечает» и говорит это в тексте ошибки.
4. `docs/15-api-websocket-spec.md` — строка Base URLs приводится в соответствие
   с перечнем эндпоинтов ниже. Без этого канон продолжит порождать тот же
   дефект.

## Что НЕ меняется

- **Пути REST не переименовываются.** Вариант «перенести всё под `/api`» был
  бы шире: он задел бы бэкенд, фронт, тесты и половину doc 15. Здесь правится
  та строка канона, которая противоречит остальным, — одна, а не двадцать.
- Протокол ws (doc 15), порт 5273, поведение голосового цикла.
- Бэкенд не трогается ни строкой.

## Acceptance examples

| # | Вход | Ожидаемый выход |
|---|---|---|
| C1 | `fetch('/sessions/interviews')` со страницы dev-сервера | JSON со списком, `content-type: application/json` — не HTML |
| C2 | Браузер: вкладка History при живом бэкенде | Список сессий; для сессии, закрытой разрывом, видно время окончания |
| C3 | Браузер: вкладка Useful Words | Содержимое банка (пустое состояние тоже годится) — не «Failed to load» |
| C4 | Клиент получил HTML вместо JSON (ошибочный вход: префикс забыт в прокси) | Ошибка называет причину — не пришёл JSON, — а не `Unexpected token '<'` |
| C5 | В `lib/api.ts` появился путь с новым префиксом, в прокси его нет | Тест-сторож красный (граничный случай: именно это и произошло 2026-07-05 и не заметилось) |
| C6 | `npm run build` и фронтовые тесты | Зелёные: правка конфига сборку не ломает |

## Non-functional

- Прокси только для dev-сервера; продовая сборка ничего о нём не знает.
- Новых зависимостей нет.

## Оракулы

- **C1, C2, C3** — браузерный стенд (§12.6, исполнение рискового пути).
- **C4, C5** — тесты фронта (vitest).
- **C6** — `npm run build` + `npm test`, smoke S3/S4.
