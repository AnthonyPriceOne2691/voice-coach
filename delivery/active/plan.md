# Plan: History и Useful Words на новый язык

Продолжение разреза, выбранного человеком в поставке 1. Визуальное направление
утверждено там же макетом — здесь оно применяется, новых решений о виде нет.

## Уроки архива (§2.2a)

| Урок | Как применён |
|---|---|
| **L42** — разрез UI не бесплатен; `@import` первым, legacy сильнее нового | Прямо предмет: поставка снимает временную границу, заведённую по этому уроку. Удаление legacy делается ЦЕЛИКОМ, потому что после переезда её не нужен ни один экран |
| **L41** — «некрасиво» становится списком дефектов от снимка | Диагноз в спеке снят со снимка приёмки поставки 1, а не придуман |
| **L17/L16** — оракул видимого — снимок; состояния должны быть различимы | H1–H6 проверяются снимками; H3 требует РАЗЛИЧИМОСТИ состояний таблетками, а не наличия текста |
| **L11** — два набора правил для одного объекта разъедутся | Подвкладки берут `.tab` шапки вместо своего `.subtab`; `TranscriptView` переходит на `.bubble*` вместо второго вида диалога |
| **L23** — адрес важнее объёма | Удалить legacy мало: надо было найти всех потребителей старых классов. Найдены `grep`'ом, включая `ListState` вне страниц |
| **L30/L32/L35** — гейты меряют не то, что называют | Прогон гейтов после каждого шага; eslint-ратчет сверяется до пуша |
| **L5–L10** — висы и разрывы | Не применимы: бэкенд не тронут вовсе |

## Порядок

CSS переехавших экранов → History → деталь и транскрипт → Words и разбор →
удаление legacy → снимки ПОСЛЕ удаления → doc 17.

## Rejected alternatives

- **Выпиливать legacy постепенно** вместо удаления целиком — отклонено, потому
  что после этой поставки её не нужен ни один экран, и «на всякий случай»
  оставленный мёртвый CSS есть ровно тот долг, который поставка закрывает.
- **Оставить `.subtab` отдельным классом** вместо `.tab` — отклонено, потому что
  это один и тот же элемент интерфейса, и два набора правил разъедутся (L11).
- **Снять `max-height` у `.turns`** вместо нового `.turns-full` — отклонено,
  потому что в живой сессии ограничение нужно, а в сохранённом транскрипте нет.
