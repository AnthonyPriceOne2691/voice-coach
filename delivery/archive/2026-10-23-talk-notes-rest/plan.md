# Plan: REST разговоров и заметок «было → лучше» (talk-notes-rest, D3a.2 — 2 из 3, слой 1 из 2)

## Approach

**Заметки только читаются.** Их пишет проверка речи (talk-check, ведущая сессия) в
`talk_sessions.metadata_json["language_notes"]` по контракту из `spec.md`. Эта
поставка их отдаёт, озвучивает и кладёт в банк слов — и ни одного решения «что
считать заметкой» не принимает. Тесты создают строки разговора с такими метаданными
напрямую, без проверки речи.

**Разрез по слоям.** Собранная talk-notes (REST + экран) весила 1,044 строки ещё без
доков при пределе 800; по правилу спеки она режется без waiver. Эта поставка — REST и
доки 10, 12, 15. Экран (Language notes, Listen, Add to Useful Words, разговоры в
History) и doc 17 — следующая, talk-notes-screen: её коммиты уже собраны и зелёные на
локальной ветке и ждут мержа этой.

**REST — свой модуль `api/routes_talks.py`.** `ws_voice.py` не трогается.

| Эндпоинт | Что |
|---|---|
| `GET /sessions/talks?limit&offset` | страница разговоров, новые первыми; `limit` 1…100 (гейт unbounded-list) |
| `GET /sessions/talks/{id}` | разговор + транскрипт + `language_notes` |
| `POST /sessions/talks/{id}/notes/{n}/vocabulary` | фраза `better` → Useful Words |
| `GET /sessions/talks/{id}/notes/{n}/audio` | WAV фразы `better` темпом пользователя |

**Длительность разговора — из `ended_at − started_at`.** В метаданных разговора
`duration_sec` нет (у интервью он пишется оркестратором). У разговора без `ended_at`
длительность `null`: число не было бы итогом, и History ставит «not finished» по
`ended_at`, как у интервью (L16).

**Add to Useful Words (C12):**
1. термин уже в банке (без регистра, как dedup doc 10) — ответ `exists`, модель не
   зовётся, `times_seen` не растёт: повторный клик — не «встретилось снова»;
2. термин в банке, но удалён человеком — запись возвращается (`added`): правило
   doc 10 «удалённое не добавлять» защищает от экстрактора, а не от явной просьбы;
3. иначе перевод на qwen тем же `SummaryService.translate_term`, что чинит банк
   (L57: не на R1). Usage — фраза Антона с уже исправленным фрагментом. Перевод
   судит S-H6 (`translation_problem`): негодный — 502 и ничего не записано; модель
   недоступна — тоже 502. Запись — через `VocabularyRepository.merge`; `type` —
   `word` или `phrase` по числу слов, `category` — `fluency`, `context_note_en` —
   «You said: “…” — причина».

**Listen (C11).** Темп — тот же коридор, что у голосовой сессии: сохранённый
`speech_length_scale`, если он число в коридоре, иначе `Settings.piper_length_scale`.
Синтез получает темп явным аргументом КАЖДОГО вызова (L29).

## Stack / boundaries

| Файл | Что |
|---|---|
| `backend/app/api/routes_talks.py` | четыре эндпоинта, чтение заметок, сборка записи банка |
| `backend/app/main.py` | регистрация роутера |

| `backend/app/storage/repositories/vocabulary.py` | `find_term`, `restore`; поиск по термину — общий с `merge` |
| `backend/tests/test_rest_talks.py` | REST-оракулы C10–C13 |

Не меняются: `ws_voice.py`, `talk_flow.py`, `orchestrator/talk.py` (их правит
talk-check), `summary/**` и промпт перевода, весь фронт (talk-notes-screen).

## Rejected alternatives

- **Одна поставка REST + экран с waiver `max_loc_diff`** — отклонено, потому что
  подписанная спека велит при превышении резать дальше без waiver, а человек уже
  выбирал «резать мельче» на D3a.1; слои проверяются независимо (экран — на
  подменённом `fetch`).
- **Добавлять в банк одним `merge` без проверки наличия** — отклонено, потому что
  `merge` на существующем термине поднимает `times_seen`, а удалённый пропускает
  молча: экран сказал бы «уже там» про слово, которого в Useful Words не видно.
- **Перевод на R1** — отклонено, потому что D-8 и L57: R1 — источник утечки CJK в
  переводах, починку он и вызвал.
- **Звук через WS** — отклонено, потому что после конца разговора сессии нет, а
  `GET` с WAV проигрывается браузером штатно (`new Audio(url)`).

## Risks

- **Контракт с параллельной talk-check** — читаются только поля контракта; заметка
  без строк `said`/`better` — нарушение контракта: она пропускается с записью в лог,
  а не роняет экран.
- **Перевод ФРАЗ — новый класс входа** для промпта, написанного под термин (L33,
  L76). S-H6 отвечает «не мусор ли», а не «хорошо ли» (L58): качество перевода фраз
  проверяет человек на живой модели по «запускай»; в сигнале наблюдения — доля
  отвергнутых.
- **Порядок мержа** — сначала контур (#41), потом talk-check, потом эта; после мержа
  контура ветка перебазируется на `origin/main`, строка `stack:` сверяется со снимком.

## Уроки архива по затронутым путям (§2.2a)

- **L5, L6, L7** — `main.py` тронут только регистрацией роутера; lifespan и уборка ws
  не меняются; `delivery_check` гоняется руками с `--diff-base origin/main`.
- **L11, L12, L13, L14, L15** — новые адреса живут под `/sessions`, прокси его уже
  покрывает (doc 15 — без нового префикса); venv и node_modules — свои каталоги
  worktree, коммит по явным путям.
- **L28, L29, L30, L31, L32** — темп Listen — значение каждого вызова синтеза
  (`FakeTts.scales`); jscpd до и после; покрытие диффа гоняется отдельно от
  `run_checks`, `coverage.json` в коммит не попадает.
- **L33, L34, L35, L36** — перевод фразы — новый класс данных для промпта термина;
  OKF-гейт гоняется после коммита, не до.
- **L41, L42, L43, L44** — данные для экрана есть в API до вёрстки: `session_id` в
  `session_ended`, `language_notes` в детали; doc 15 описывает их до экрана.
- **L51, L52, L53, L54** — `runtime_paths` пересмотрен: новых путей, видимых только
  исполнением, поставка не задевает — REST исполняют тесты.
- **L55, L56, L57, L58, L59** — перевод судит S-H6, перевод делает qwen, качество
  фраз — человек; `summary/**` не трогается, OKF-концепт model-split не задет.
- **L60, L61, L62** — модель в тестах управляемая (`ScriptedLlm`, падающий двойник);
  каждый новый сторож проходит мутацию в той же сессии.
- **L69, L70** — `rule_enforcers.md`: у промпта перевода появился новый вход — строка
  про фразы из заметок; живая база человека не трогается.
- **L77, L79** — предохранитель меряется на собранной ветке (замер и дал разрез);
  коммиты по слоям без stash.
- **L80, L81** — не применимы: прогрева и замера латентности в поставке нет.

## Test / eval strategy

- **C13** (REST) — `test_rest_talks.py`: страница ограничена (`limit` 0 и 101,
  `offset` −1 — 422), новые первыми, число заметок, длительность и `null` у
  незаконченного; деталь с транскриптом.
- **C10** (REST) — деталь отдаёт заметки по порядку разговора; без ключа — пусто;
  заметка вне контракта не роняет ответ.
- **C11** (REST) — WAV лучшего варианта темпом из настроек; вне коридора и не число —
  умолчание; значение каждого вызова синтеза.
- **C12** — перевод по-русски одним вызовом голосовой модели; повтор не дублирует и
  модель не зовёт; негодный перевод и молчащая модель — 502 без записи; удалённое
  возвращается; 404 на чужой разговор, номер вне списка и отрицательный.
- Экранная половина C10–C13 — talk-notes-screen. Живое — по «запускай»: перевод
  фраз на qwen (качество, L58) и Listen голосом Piper.
