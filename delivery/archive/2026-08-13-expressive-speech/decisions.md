# Decisions: expressive-speech

| # | Решение | Кто | Почему |
|---|---|---|---|
| D1 | Вариант D спайка: интонация + ритм + паузы на текущем голосе | human:anthony | Выбран на слух из пяти образцов. Выразительности удалось добиться без смены голоса — за 41 ms против 225 у `ryan-high` |
| D2 | `ryan-high` отклонён | human:anthony | Стоил бы 185 ms сверх и сделал бы Генри другим человеком ради того, чего добились настройками |
| D3 | Пауза ПЕРЕД чанком, кроме первого | human:anthony | Пауза после последнего предложения — задержка перед открытием микрофона, то есть плата на каждом ходе за тишину, которую никто не услышит |
| D4 | Параметры — в `Settings`, не в REST/UI | human:anthony | Это характер голоса, а не предпочтение на каждый день; код и тесты ради однократной настройки не окупаются |
| D5 | Пауза живёт в байтах WAV, а не в `AudioQueue` | agent | Клиент остаётся глупым, правка работает в любом клиенте, и поставке не нужен браузерный оракул |
| D6 | Вставка — в `_send_audio`, а не в `TurnRunner` | agent | Одним местом закрываются все пути с несколькими чанками: ход интервью, подтверждение темпа с повтором, Mode 2. Два места вставки разъехались бы (L11) |
| D7 | Просодия — в конструкторе `PiperTts`, а не на шве `TextToSpeech` | agent | В отличие от темпа её никто не меняет на лету; класть на шов значило бы объявить изменяемым то, что не меняется |
| D8 | `noise_scale`/`noise_w_scale` передаются ЯВНО | agent | `None` означает «взять паспорт», а паспорт голоса Генри вдвое ровнее стандартного. Молчание кода было согласием с ровностью, и ни один тест этого не видел |
| D9 | `FakeTts` отдаёт настоящий WAV | agent | Двойник обязан быть подстановочным. `b"WAV:"+text` сходило с рук, пока аудио никто не читал; первый же такой код уронил шесть тестов |
| D10 | `fake_tts_duration_s` считает ожидаемую длительность, а не синтезирует | agent | Тест про паузу должен сравнивать с числом, а не с результатом того же кода, который проверяет |
| D11 | Разметка пауз по пунктуации отложена | agent | Сначала надо услышать, мешает ли ровность одинаковой паузы. Оптимизировать неизмеренное — гадание |
| D12 | `config.py` оставлен в `implementation:` у `model-split.md` | human:anthony | Ложные срабатывания на каждой новой настройке — цена настоящего сторожа: подмена модели в конфиге обязана заставлять перечитать D-8 |
