# Diagnosis: по History нельзя отличить закрытую сессию от брошенной

## Симптом (дословно, машиной)

Строка History для сессии, брошенной посреди хода **до** починки разрыва
(`ended_at` пустой навсегда):

```
Aug 12, 10:44 AM · 33 s · in_progress
```

Строка для сессии, корректно закрытой уборкой **после** починки:

```
Aug 12, 04:33 PM · 34 s · in_progress
```

Различить нельзя: обе показывают дату начала, длительность и `in_progress`.
Ответ API при этом различается однозначно:

```json
{"ended_at": null,                        "duration_sec": 33}   // брошена
{"ended_at": "2026-08-12T13:33:55+00:00", "duration_sec": 34}   // закрыта
```

## Журнал гипотез

- **H1 — «`duration_sec` не заполняется у брошенной сессии, поэтому по нему и
  надо судить».** **ОПРОВЕРГНУТА замером:** у брошенной сессии
  `duration_sec = 33`. Причина видна в коде: значение пишется в `metadata_json`
  при КАЖДОМ flush'е хода (`ws_voice.py:353`,
  `orchestrator/interview.py:112`), то есть отражает «последний записанный
  момент», а не конец сессии.
- **H2 — «UI показывает `ended_at`, просто в другом месте».**
  **ОПРОВЕРГНУТА чтением:** `grep -n "ended_at" frontend/src/` не находит ни
  одного вхождения в компонентах. Рендерятся только `started_at` и
  `duration_sec` (`HistoryPage.tsx:103` и `:153`).

## Корневая причина

Поле `ended_at` доезжает до фронта в JSON (`routes_sessions.py:23`) и **не
используется ни одним компонентом**. Единственный видимый признак завершённости
— `duration_sec`, который завершённости не означает.

Отсюда прямое следствие: пример B6 поставки `ws-disconnect-mid-turn` («увидеть
сессию в History с временем окончания») нынешним UI **непроверяем** — не потому
что данных нет, а потому что их некому показать.

## Что это НЕ

- **Не дефект бэкенда.** `ended_at` пишется корректно (это чинила поставка
  `ws-disconnect-mid-turn`) и корректно отдаётся в API.
- **Не про `status`.** Статус `in_progress` у брошенной сессии — намеренное
  поведение: интервью не было завершено пользователем. Различать надо не
  статусы, а **дошла ли уборка до конца**.
