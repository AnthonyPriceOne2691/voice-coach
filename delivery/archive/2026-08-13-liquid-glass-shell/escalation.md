# Escalation: пробиты оба объёмных breaker'а

**Замер** (`delivery_check.py --diff-base origin/main`):

```
files=31 net_loc=1003 (+1493/-490)
limits={'max_files_touched': 25, 'max_loc_diff': 800}
```

## Из чего состоит дифф

| Группа | Файлов | Строк |
|---|---|---|
| `frontend/src/styles/**` (токены, база, экраны) | 3 | **+822** |
| `frontend/src/pages/**` (4 экрана, один новый) | 4 | +302 −87 |
| `frontend/src/components/**` | 6 | +123 −29 |
| `backend/**` (счётчик вопросов, вынос фабрики сессий, тесты) | 4 | +125 −35 |
| `docs/15`, `docs/17` | 2 | +20 −5 |
| прочее (`App.tsx`, `api.ts`, типы, хук, `vite.config.ts`) | 12 | небольшие |

**822 строки из 1003 — это CSS**, то есть один файл стилей, разложенный на три и
переписанный целиком. Кода на TypeScript прибавилось около 300 строк, и из них
~160 — новый экран Settings, которого раньше не было вовсе.

## Вариант A — human waiver на одну поставку

`waivers: max_files_touched=35 max_loc_diff=1100 reason=… by=human:anthony`

**Цена:** объёмные breaker'ы перестают защищать эту поставку. Против этого
работает то, что дифф почти весь декларативный (CSS), а поведенческая часть
покрыта 162 тестами бэкенда, 20 фронта и снимками всех четырёх экранов.

**Что получаем:** один связный интерфейс, одно окно наблюдения, одна приёмка.

## Вариант B — разрезать по экранам

Граница техническая: сначала общий слой (`styles/**` + `App.tsx` + шапка), потом
по экрану на поставку.

**Цена:**

1. **Общий слой всё равно задевает все экраны.** Токены, `.glass`, шапка и
   кнопки — это и есть 822 строки. Первая поставка была бы почти такой же
   большой, но при этом ломала бы вид остальных трёх экранов: старые классы
   (`.history-item`, `.word-card`, `.transcript`) исчезли, новые к ним ещё не
   применены. То есть между поставками интерфейс **наполовину сломан** — не
   «половина в старом стиле», а буквально без стилей.
2. **Три-четыре окна наблюдения** вместо одного, при том что незакрытых уже
   одиннадцать (25–27 августа).
3. Три комплекта spec/plan/verify и три приёмки глазами вместо одной.

**Что получаем:** формальное соблюдение лимитов.

## Рекомендация исполнителя

**Вариант A.** Разрез здесь не уменьшает риск, а увеличивает его: он не режет
изменение на независимые части, потому что независимых частей нет — визуальный
язык по определению общий. Промежуточное состояние («стили переписаны, половина
экранов их не знает») хуже и для проверки, и для использования.

Отдельно стоит сказать честно: **план это предсказывал**, и человек подписал
«четыре экрана одной поставкой» до кода. Эта эскалация — не новость, а замер
обещанного.

Решение за человеком: waiver — подпись, и агент её ставить не вправе (§2.2b).
