# Decisions: speech-pace

Одна строка на выбор (§12.2). Отклонённые варианты с причинами — `plan.md`,
секция Rejected alternatives.

| # | Решение | Кто | Почему |
|---|---|---|---|
| D1 | Просьба о темпе — **мета-ход**: состояние интервью не двигается | agent | Иначе просьба стоит вопроса из шести и оседает в транскрипте против чужого `question_id` — то есть портит вход Mode 2 и суммаризации |
| D2 | Ответ = подтверждение + **дословный** повтор, без вызова LLM | human:anthony | Просьба «медленнее» почти всегда означает «я не расслышал»; повтор её закрывает, а отсутствие вызова делает ход быстрее обычного и снимает риск нарушения контракта |
| D3 | Темп хранится в kv-настройках и переживает сессию | human:anthony | Просить каждый раз — та же работа заново; заодно готовая точка подключения регулятора в будущем UI |
| D4 | Шаг 0.15, коридор 0.85–1.60 | human:anthony | Пять ступеней от заметно быстрее до заметно медленнее; замерено: коридор растягивает фразу в 1.53× |
| D5 | `length_scale` — необязательный аргумент на шве `TextToSpeech` | agent | Темп решается **на реплику**, а не на процесс. Шов расширяется, а не ломается: у всех существующих вызовов поведение прежнее |
| D6 | Носитель темпа — адаптер `PacedTts` на сессию | agent | Протаскивать темп через `TurnRunner.run()` значит дать раннеру знание, которым он не владеет; мутировать общий `PiperTts` — дать темпу утечь в параллельную сессию. Голосовая модель при этом остаётся одна на процесс |
| D7 | Порог «просьба короче 12 слов» | agent | Единственное, что отделяет P1 от P4. Цена ложного срабатывания (содержательный ответ пропал из транскрипта) выше цены пропуска (просьбу не услышали) — §4.3b, поэтому порог смещён в сторону «скорее ответ» |
| D8 | Таблица формулировок — в коде, а не в `data/` | agent | `data/` в этом проекте — то, что читает **модель** (промпты, контракты, вопросы). Таблица распознавания — политика, её место рядом с политикой follow-up. Цена: новая формулировка требует правки `.py` |
| D9 | Реплики подтверждения — в `data/prompts/templates/` | agent | Это, наоборот, **произносимый текст**; в коде ему не место (doc 18) |
| D10 | На границе коридора звучит **другая** реплика | agent | Подтвердить изменение, которого не произошло, значит соврать голосом; молчаливый отказ — тот же класс, что молчаливый зажим в API |
| D11 | `PATCH /settings` отвергает значение вне коридора кодом 422 | human:anthony (через спеку) | 200 на неприменённую настройку неотличим от успеха |
| D12 | Мета-ходы отфильтрованы из `_render_transcript` | agent | Иначе просьба уедет в промпт R1 как реплика кандидата и попадёт в оценку и evidence |
| D13 | Мета-ход **флашится** в транскрипт наравне с остальными | agent | Отбрасывать — работа читателя: не записать ход значит потерять его навсегда, а отфильтровать можно в любой момент (concept `transcript-durability`) |
| D14 | Дефолт настройки приходит из конфига параметром конструктора репозитория | agent | Второй литерал `1.15` в другом файле — форма L11 (два файла, каждый со своей половиной правды). Сторожится тестом на совпадение с `Settings` |
| D15 | Фронт не трогается | human:anthony (через спеку) | Экрана Settings нет вовсе; регулятор — часть переработки интерфейса. Иначе поставка тянет за собой браузерный оракул (L17) |
| D16 | Waiver на `max_files_touched=30` вместо разреза на две поставки | human:anthony | Blast radius узкий, перебор дают тесты и доки; разрез купил бы соблюдение лимита ценой поставки из мёртвого кода и девятого окна наблюдения (`escalation.md`) |
| D17 | `canon_drift_waiver` на `model-split.md` | human:anthony | Тронут `summary/service.py`, но разделение моделей не менялось; править concept «чтобы позеленело» канон запрещает прямо |
| D19 | Общая часть двух флоу вынесена в `voice/session_flow.py` | human:anthony | jscpd упёрся: `on_meta` встал в середину 36 строк, которые `InterviewFlow` и `ReviewFlow` дублировали ДО поставки, и разрезал одну клон-пару на две. Замерено на `origin/main`: пара была одна. Выбрано чинить, а не пересниматься — снимок ушёл с 1 до **0**, и ратчет теперь защищает улучшение |
| D18 | `hypothesis` не добавляется | human:anthony | Инвариант коридора уже проверяется перебором; зависимость ради формы гейта не берём. Долг записан в verify-report |
