# Plan: мутационный гейт судит на этом проекте и стоит в CI на каждом PR

## Approach

**Чинить проект, а не канонный скрипт.** Все три стены (`diagnosis.md`) — свойства
проекта: модуль, который не импортируется под копией, корень по глубине пути и порог
покрытия в `addopts`. Скрипты гейта (`scripts/lint/*mutation*`) не трогаются — значит,
и адаптаций в `adapted.json` по ним нет.

1. **Корень по данным.** `find_repo_root(start)` в `app/config.py`: ближайший предок,
   где лежат `data/prompts` и `data/contracts` (оба — без них приложение не стартует);
   нет — `RepoRootNotFoundError` с путём старта и именами маркеров. `REPO_ROOT` —
   модульная константа, как была. Тесты берут его из `app.config`: тринадцать файлов
   с `parents[2]` правятся механически.
2. **Импорт копии.** `vocabulary.py` получает `from __future__ import annotations`;
   сторож `test_mutation_copy.py` проходит AST пакета и называет метод, который
   прячет имя из аннотации, вычисляемой в теле класса, если модуль не отложил
   аннотации.
3. **`--no-cov` для прогонов mutmut** — `[tool.mutmut] pytest_add_cli_args`.
   Обычный `pytest` и `ci.yml` судят покрытие как раньше.
4. **`TurnEnforcer` — обычный класс.** Под `@dataclass` mutmut не видит ни одной
   проверки контракта. `__init__` повторяет поля dataclass'а; `ContractEnforcer`
   создаёт его по ключевым словам — как раньше.
5. **Тесты прогрева** — `test_warmup.py`: формат WAV для whisper, параметры вызова
   модели, отказы (M8–M10).
6. **Замер долей** по модулям M11: гейт и `mutmut run` с глобами, на свежем
   `mutants/` (кэш mutmut держит статистику прошлого кода — новые функции на нём
   выглядят «no tests»).
7. **CI-шаг** — дословно канонный блок `quality.yml` («Mutation testing (changed
   files, budgeted)», только PR, `MIN_KILLED=60`, `BUDGET_SEC=300`, `if: always() &&
   github.event_name == 'pull_request'`) последним шагом джобы `gates`.
8. **Учёт контура** — `adapted.json` (запись `quality.yml`), «Остатки обновления
   2.69» в `STACK-ACCEPTANCE.md`.

## Rejected alternatives

- **Переменная окружения с корнем (`VIC_REPO_ROOT`)** — отклонена, потому что второй
  источник правды о корне, а задать её пришлось бы в канонном скрипте гейта или в
  каждом месте вызова; без неё — та же поломка. Поиск по данным работает в любой
  раскладке без настройки.
- **Счёт `parents[3]` под mutmut / проверка `"mutants" in __file__`** — отклонены,
  потому что это знание о раскладке чужого инструмента в коде продукта: следующая
  раскладка (worktree, другой мутатор) сломает его снова.
- **Скопировать `data/` в `mutants/` через `also_copy`** — отклонено, потому что
  `also_copy` берёт пути от `backend/`, и `../data` легло бы в `backend/data` вместе
  с моделями (сотни мегабайт) и приватными `data/sessions`.
- **`do_not_mutate` для `vocabulary.py` или `# pragma: no mutate` на методе `list`** —
  отклонено, потому что исключение из гейта — дыра: модуль перестал бы судиться
  совсем (урок L55 — исключение, не покрытое другим правилом).
- **Переименовать метод `list`** — отклонено, потому что меняет API репозитория и
  его вызывающих ради инструмента; отложенные аннотации снимают класс целиком, без
  правки вызовов.
- **Убрать `--cov-fail-under` из `addopts`** — отклонено, потому что порог покрытия
  держит `ci.yml` (`uv run pytest`) и локальный `run_checks.sh`; `--no-cov` только в
  прогонах mutmut меняет ровно то, что сломано.
- **Оставить `TurnEnforcer` dataclass'ом и назвать пятно в отчёте** — отклонено,
  потому что енфорсер — главный исполнитель правил («запрет ищи в рантайм-контракте»,
  CLAUDE.md): гейт, который на нём показывает 100% по 21 мутанту из фабрики, хуже
  отсутствующего. Цена — 10 строк без изменения поведения; тесты контрактов те же.
- **Поднять `BUDGET_SEC` или резать `ws_voice.py` в этой поставке** — отклонено,
  потому что это решение о цене CI и об архитектуре, а не починка гейта: здесь
  замеряется и предъявляется человеку (open question спеки).

## Risks

- **Тринадцать тестовых файлов** — правка механическая (`parents[2]` → `REPO_ROOT`);
  сьют целиком зелёный, число тестов не меняется (кроме новых).
- **`TurnEnforcer`** — на критическом пути doc 13. Держат тесты контрактов и
  `turn_runner` без правок; гейт на этом же PR судит файл целиком.
- **Шаг CI на будущих PR** — PR, трогающий `api/ws_voice.py`, может не уложиться в
  300 s: «бюджет исчерпан» — красное. Замер — в verify-report.

## Уроки архива по затронутым путям (§2.2a)

- **L37, L38, L39, L40** (`backend/app/config.py`) — молчаливые умолчания: корень
  тоже был умолчанием, которое никто не проверял под другой раскладкой; двойник
  обязан быть подстановочным — копия `config.py` в M2 исполняется настоящая, а не
  имитируется вызовом функции.
- **L60, L61, L62** (`backend/tests/helpers.py`) — управляемость вместо подлинности;
  новый тест-сторож проходит мутацию в ту же сессию: сторож M5 проверен на файле без
  отложенных аннотаций, тесты прогрева — гейтом (M7).
- **L63, L64, L65** (`backend/tests/test_gate_defects.py`, `scripts/lint/adapted.json`)
  — гейт лжёт или я не согласен с правилом: здесь гейт честно говорил «не просудил»,
  чинится проект; канонные скрипты не трогаются, порог и бюджет не меняются.
- **L20, L21, L22, L23, L74, L75** (`backend/tests/test_knowledge_profile.py`) — файл
  тронут только источником корня; бюджет и покрытие профиля не меняются.
- **L72** (`backend/tests/test_settings_readers.py`) — оракул на перечень: поиск
  читателей идёт по настоящему дереву и под копией mutmut тоже.
- **L73** (`backend/tests/test_turn_runner.py`) — только источник корня.
- **L55, L56, L57, L58, L59** (`backend/app/storage/repositories/vocabulary.py`) —
  исключение без замены — дыра: поэтому не `do_not_mutate`, а отложенные аннотации.
- **L18, L19** (`.github/workflows/quality.yml`) — шаг на условии `pull_request`
  исполняется в этом PR; ветка push им не проверяется — шаг на push не нужен по
  канону, и это видно в логе прогона `main` после мержа.
- **L1, L2, L3, L4** (`.github/workflows/`) — «CI красный» — не одно состояние:
  смотреть шаг по имени в логе; зелёный гейт без половины неотличим снаружи — отсюда
  слепое пятно декораторов в отчёте; база диффа — `origin/main`.
- **L24, L48, L11** — названы внутри строк L73, L65 и L39, чьи пути дифф задевает. L24 — запрет живёт в рантайм-контракте: ровно поэтому енфорсер обязан быть виден гейту (снят `@dataclass`). L48 — breaker объёма и сгенерированное: здесь не применим, lock-файлы не трогаются (mutmut уже в замке). L11 — две половины канона, каждая верная, вместе не работают: тот же класс, что `--cov-fail-under` проекта против прогона mutmut — каждая настройка верна сама по себе.
- **L80, L81** (`voice/warmup.py`, тесты) — прогрев кладёт префикс, а не «hi»; замер
  на нагруженной машине врёт: каждое время записано вместе с load average.
